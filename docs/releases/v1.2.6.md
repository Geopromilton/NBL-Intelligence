# NBL-Intelligence 1.2.6

- The installed app now refreshes its copy of the site registry (site.yaml) when the program version changes. Before, the copy made on first start was never updated, so the installed app kept the old AquaTwin run, the old roof area result and the old recharge zones while the website showed the new ones. The old file is kept as site.yaml.bak-<version>, and the cached 3D scene is rebuilt from the current run.
