# NBL-Intelligence 1.2.2

Fix for deep-think answers.

- An answer is always shown. Before, if the model's final reply was not strict JSON (for example a long answer with raw line breaks), the question could end with no answer.
- Replies with raw line breaks inside the answer are now read correctly.
- The AI may read up to 10 engine results for one answer (was 6), which broad questions need.
- The deep-think box separates the model's thinking for each step.
