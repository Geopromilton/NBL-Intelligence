## NBL-Intelligence 1.1.0

First standalone release.

**Install once:** download `NBL-Intelligence_Setup_1.1.0.exe` and run it (no administrator rights needed). It installs to your user folder with its own Python runtime, and adds Start-menu and desktop shortcuts.

**Updates without reinstalling:** later versions arrive in Settings → Updates (Download and install, then Restart). Only the program is replaced; sites, runs, decisions, reports and settings are never touched. The previous version is kept for roll-back.

### What's in it
- NVIDIA reasoning with answers written word by word, model list from your NVIDIA account, automatic fallback model, and recovery when a model's reply is malformed
- 3D site twin with clickable sites, borewells, recharge rings and ADMT zones
- Explore, Water plan (persons per flat 2-6), Recharge, Scenarios, Integrity, Decisions, Knowledge and Word reports
- New NBL-Intelligence logo, welcome screen, update banner and smaller-screen layout

### Engines
NBL-Intelligence reads and runs NBL-AquaTwin and NBL-WaterPlan from their own folders (default `D:\NBL-AquaTwin` and `D:\NBL-WaterPlan`; change them in Settings).
