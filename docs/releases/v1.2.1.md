# NBL-Intelligence 1.2.1

AI model update, with deep think.

- **New default AI model: NVIDIA Nemotron 3.5 Super VL** (`nvidia/nemotron-3.5-super-vl-120b-a12b`). Fallback: Nemotron 3.5 Lightning (`nvidia/nemotron-3.5-lightning-30b-a3b`). NVIDIA retired the previous two models (DeepSeek V4.1 Flash and Nemotron 3 Super) in October and November 2026; saved settings that still name them are switched automatically.
- **Deep think on by default.** The model reasons step by step before it answers. Its reasoning streams in a separate, folding "Thinking deeply…" box above the answer; it never mixes into the answer itself. Turn it off in Settings → NVIDIA reasoning → Deep think.
- Longer replies allowed (16,000 tokens) and a longer timeout (120 s), so reasoning has room.
- Website: the same model and deep think, through the NBL relay.
